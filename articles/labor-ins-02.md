雇主未依法為員工投保勞健保與就業保險，將面臨補繳保費、罰鍰及民事賠償等法律責任。

## 雇主違法罰則與責任

## 勞工保險（勞保）：

### 強制範圍：

- 僱用 5 人以上的公司、行號應強制投保；
- 未滿 5 人屬自願投保，但一旦自願成立投保單位後，就必須為全體員工加保。

### 罰鍰與補繳：

未辦理投保者，按自僱用之日起至參加保險前一日或離職日止應負擔之保險費金額，處 4 倍罰鍰，並追繳保險費。

### 賠償責任：

若員工發生保險事故（如生育、傷病、失能、死亡、老年等）卻無法請領勞保給付，雇主須依勞保給付標準負擔賠償責任。

## 全民健康保險（健保）：

### 強制範圍：

只要僱用 1 名員工（不論人數多寡）即強制投保，必須於員工到職 3 日內辦理。

### 罰鍰與補繳：

除追繳保險費外，並按應繳納之保險費處 2 倍至 4 倍罰鍰。

## 就業保險（就保）：

### 強制範圍：

僱用 1 人以上之本國籍受僱勞工即應投保，無 5 人以下豁免。

### 罰鍰與補繳：

處應負擔保險費金額之 3 倍至 10 倍罰鍰（依具體法條與實務最高可處 10 倍），並補繳保費及依給付標準賠償勞工損失。

### 勞工職業災害保險（職災保險）：

僱用 1 人以上即強制自到職當日加保，保費全由雇主負擔，未投保者亦會面臨罰鍰與相關賠償。

## 事務所觀點

常有新成立公司的老闆詢問：

<div class="notice notice-quote">
我新成立公司，已有員工，該如何正確投保？
</div>

事務所建議：

雇主僱用員工，不論是全職、兼職（工時人員）或臨時工，皆須依員工人數依法辦理投保。以下為雇主在不同人數情境下的正確投保指南：

### 情境一：員工總人數 1～4 人

當公司或商號（不含負責人）員工人數在 4 人以下時，勞保為非強制投保，但健保、就保、職災保險與勞退皆為強制投保。

| 險種 | 是否強制投保 | 雇主正確做法 |
|-----|-------------|--------------|
| 勞工保險 (勞保) | 非強制 | 可暫不成立勞保投保單位。員工可自行透過相關職業工會加保，或由雇主自願成立投保單位為全體員工加保。 |
| 全民健保 (健保) | 兩大辦理方式：<br>1. 負責人投保：負責人若有健保，需在自家公司（投保單位）按負責人級距投保，不能在公所或眷屬名下投保。<br>2. 員工投保：只要僱用 1 人，就必須在到職日為員工辦理健保加保。 | 　 |
| 就業保險 (就保) | 強制成立「就保/職災/勞退」三合一單位，並於員工到職當日申報加保。 | 　 |
| 職業災害保險 (職保) | 強制成立並於到職當日申報。即使未成立勞保，職災保險亦屬強制範疇。 | 　 |
| 勞工退休金 (勞退) | 依《勞工退休金條例》按月為員工提繳不低於每月工資 6% 的退休金。 | 　 |

### 情境二：員工總人數 5 人（含）以上

當公司、商號（不含負責人）僱用員工滿 5 人時，所有險種皆轉為強制投保。

| 險種 | 是否強制投保 | 雇主正確做法 |
|-----|-------------|--------------|
| 勞工保險 (勞保) | 強制成立勞保投保單位，並於員工到職當日申報加保。 |  　 |
| 全民健保 (健保) | 兩大辦理方式：<br>1. 負責人投保：負責人若有健保，需在自家公司（投保單位）按負責人級距投保，不能在公所或眷屬名下投保。<br>2. 員工投保：只要僱用 1 人，就必須在到職日為員工辦理健保加保。 | 　 |
| 就業保險 (就保) | 強制隨同勞保一併申報加保。 | 　 |
| 職業災害保險 (職保) | 強制隨同勞保一併申報加保。 | 　 |
| 勞工退休金 (勞退) | 依規定按月提繳不低於每月工資 6% 的退休金。 | 　 |

</div>

### 雇主三大核心合規原則

1. 到職當天即須加保：勞保、就保、職災保險、健保、勞退均規定必須在員工「到職當日」申報。不可因為有「試用期」而遞延投保。
2. 兼職/工時人員同樣要保：即便是計時人员（如工讀生、pt）、臨時工，只要有僱用事實，就保、職災保險、勞退與健保（每週工時達12小時以上）同樣有法定投保義務，勞保則視人數規模而定。
3. 切結不投保無法律效力：即便員工因個人因素（如躲避債務、扣薪、領取其他津貼等）主動要求不投保，並簽署「自願不加保切結書」，在法律上仍屬於無效切結。一旦被檢舉或發生職災，雇主依舊會被處以罰鍰並負擔賠償責任。




**本所可協助企業合法設立投保單位，保障勞資雙方權益。**
