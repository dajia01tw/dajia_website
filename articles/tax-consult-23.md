## 記帳士事務所可以幫創業者處理哪些事？從設立到日常報稅

許多人準備創業時，第一個想到的可能是產品、客戶、店面或營業模式，但等到真正開始辦理公司設立、申請統一發票、處理帳務及申報稅務時，才發現需要面對的行政程序其實不少。

這時候，很多創業者會開始考慮：「是不是應該找記帳士事務所協助？」、「記帳士事務所除了記帳、報稅，還能幫我處理哪些事情？」

事實上，記帳士事務所可以協助的範圍，並不只是每兩個月申報一次營業稅。從創業前的公司型態選擇、營業項目及資本額初步規劃，到公司設立、稅籍登記、日常帳務處理、各項稅務申報，甚至後續公司變更及停業、解散等，都可能是事務所能提供協助的服務。

以下就從創業者實際會遇到的情況，說明記帳士事務所可以提供哪些協助。

## 一、創業之前：先協助確認適合的設立方式

創業者在正式成立公司或行號之前，通常會遇到幾個問題：

- 我應該成立有限公司、股份有限公司，還是先設立行號？
- 只有一個人創業，也可以成立公司嗎？
- 資本額應該設定多少才合理？
- 我想經營的業務，營業項目應該如何選擇？
- 預計使用住家地址登記，可以嗎？

這些問題看似只是設立登記前的準備工作，實際上卻會影響未來的經營方式、稅務處理及股東權益。

例如，個人接案、網路銷售、餐飲業、顧問服務或未來預計引進投資人的創業者，適合的組織型態可能就不一樣。如果一開始沒有考慮清楚，未來可能還需要辦理組織變更、股權調整或其他額外程序。

記帳士事務所可以先了解創業者的營業模式及未來規劃，再協助分析：

1. 公司或行號的選擇： 依照營業規模、經營風險、股東人數及未來發展方向，分析不同組織型態的差異。
2. 資本額初步規劃： 參考創業初期的資金需求、設備採購、租金及營運週轉金，協助評估合理的資本額。
3. 營業項目確認： 依照實際經營內容，協助選擇適合的營業項目，並提醒是否涉及特許業務或其他主管機關規定。
4. 登記地址評估： 提醒創業者確認地址使用條件、建物用途、租賃契約及相關限制。

需要注意的是，事務所可以協助分析及提醒，但實際經營決策仍應由創業者自行決定；如果涉及建築使用、消防、衛生或其他特許業務，也可能需要另外向相關主管機關確認。

## 二、公司或行號設立：協助處理繁瑣的登記程序

確定創業方式後，接下來就是辦理設立登記。

對第一次創業的人來說，公司設立並不是填寫一份申請書就能完成，通常還會涉及名稱預查、營業項目、股東資料、資本額、公司章程、銀行籌備處帳戶及相關文件。

以有限公司為例，設立過程通常會涉及以下事項：

- 公司名稱及營業項目預查。
- 股東、負責人及出資比例確認。
- 公司章程及設立文件準備。
- 籌備處銀行帳戶及股款繳納。
- 資本額查核簽證。
- 公司設立登記申請。
- 後續稅籍登記及統一發票相關事項。

記帳士事務所可以依照委託內容，協助準備及檢查設立文件、安排相關程序、送件申請，並提醒創業者需要配合提供的資料。

其中，依公司法規定，公司設立登記或資本額變更登記涉及資本額查核簽證時，應由符合資格的會計師辦理。若事務所本身具備相關會計師服務資源，也可以依照規定協助安排。

對創業者來說，委託事務所辦理設立的價值，不只是有人代為送件，而是能在設立前先確認資料及規劃是否合理，降低因文件錯誤、營業項目不適合或地址條件不符而反覆補件的情況。

## 三、開始營業後：日常記帳與憑證整理

公司或行號成立後，真正需要長期處理的工作才開始。

無論是銷售商品、提供服務、承接案件，或透過網路平台收款，只要有營業活動，就會產生各種收入、支出及相關憑證。

例如：

- 向客戶銷售商品或提供服務。
- 支付辦公室租金、水電費及網路費。
- 購買設備、電腦、辦公用品及營業所需材料。
- 支付員工薪資、外包費用或顧問費。
- 支付平台手續費、廣告費及物流費。

這些交易都可能影響公司的帳務及稅務處理。

記帳士事務所可以協助整理交易資料、核對收入及支出憑證、登錄帳務，並依照交易性質判斷應如何入帳。

例如，創業者購買一台電腦，究竟應該列為當期費用，還是列為固定資產並分年提列折舊？支付租金時是否涉及扣繳及相關申報？收到國外平台的收入，又應如何整理交易資料？

這些都不是單純將發票金額輸入系統就能完全處理的事情，還需要依照實際交易內容及相關稅法規定判斷。

此外，事務所也可以提醒創業者平時應保留哪些憑證及資料，避免到了申報期間才發現資料不完整。

## 四、定期稅務申報：避免漏報及錯誤申報

對多數創業者而言，稅務申報是委託記帳士事務所最常見的服務項目。

公司及行號依照其課稅方式、實際交易及適用規定，可能涉及不同的稅務申報義務。

常見項目如下：

| 稅務項目 | 主要處理內容 |
|-----|-----|
| 營業稅申報 | 整理銷售額、進項憑證及相關資料，依規定辦理申報 |
| 營利事業所得稅 | 整理年度收入、成本及費用，辦理結算申報 |
| 各類所得扣繳 | 針對薪資、租金、佣金、執行業務報酬等給付，依規定辦理扣繳及申報 |
| 各類所得憑單 | 依規定整理及申報所得資料 |
| 未分配盈餘申報 | 依公司盈餘分配及相關規定，評估是否涉及申報義務 |

例如，公司每兩個月通常需要依規定辦理營業稅申報，即使當期沒有營業收入，也不能直接認為不需要申報。

每年辦理營利事業所得稅結算申報時，也需要依照帳務資料整理收入、成本、費用及相關調整事項，而不是單純將銀行帳戶的收支總額當成公司所得。

如果公司有支付員工薪資、房東租金或其他應扣繳所得，也可能涉及扣繳及所得憑單申報。

因此，委託事務所處理帳務及稅務申報，可以讓創業者更清楚掌握應申報的項目及時間，降低因不熟悉規定而漏報、遲報或錯誤申報的風險。

## 五、開始聘請員工：協助薪資及相關申報事項

當創業規模逐漸擴大，開始聘請員工時，除了每個月支付薪資，還會增加勞健保、勞工退休金及薪資所得扣繳等相關事項。

記帳士事務所可以依照委託範圍，協助處理或提醒下列工作：

- 員工薪資及相關帳務整理。
- 薪資所得扣繳及所得資料申報。
- 勞保、就業保險、職災保險及健保投保相關行政作業。
- 勞工退休金提繳相關事項。
- 每月薪資資料與公司帳務核對。

不過，聘僱員工涉及的規定不只有稅務，還包括勞動契約、工時、加班費、休假、資遣及勞資爭議等勞動法令。

事務所可以依照專業及服務範圍提供行政協助或相關提醒，但若涉及勞動法令的個案判斷、勞資爭議或法律訴訟，仍應視情況尋求勞動法令專業人士或律師協助。

## 六、公司經營過程中的變更及其他行政事項

公司成立後，經營狀況可能隨時改變。

例如，公司原本在住家登記，後來租用辦公室；原本只有一位股東，後來有新投資人加入；或者原本經營單一業務，後來增加新的營業項目。

這些情況可能涉及公司或商業登記變更，也可能需要同步處理稅籍資料及其他主管機關程序。

常見的變更及後續服務包括：

| 服務項目 | 常見情況 |
|-----|-----|
| 公司地址變更 | 搬遷辦公室、營業場所變更 |
| 公司名稱變更 | 品牌調整、企業形象更新 |
| 營業項目變更 | 增加新的商品或服務 |
| 負責人變更 | 經營權或負責人調整 |
| 增資或減資 | 營運資金需求、股東出資調整 |
| 股東及股權變動 | 新股東加入、股權轉讓 |
| 停業及復業 | 暫時停止或恢復營業 |
| 解散及清算 | 決定結束公司營運 |

不同變更事項所需文件及程序並不相同，有些還會涉及股東會或董事會決議、股權安排、資本額查核及其他法律程序。

如果公司未來有引進投資人、股東變動或增資計畫，建議在交易發生前先與事務所討論，避免事後才發現程序或稅務處理不符合預期。

## 七、外國人投資、特許行業及跨境交易等特殊需求

有些創業者的需求並不只是一般公司設立及記帳報稅。

例如，外國人想在台灣成立公司、外國公司想投資台灣企業，或是公司從事特定需要許可的行業，就可能涉及其他主管機關的審查及申請程序。

另外，若公司有國外客戶、國外供應商、跨境服務收入或外幣收付款，也可能涉及營業稅、所得稅及相關憑證認定問題。

這類案件通常需要先了解實際交易模式，再判斷應辦理哪些登記、申報或許可程序。

例如：

- 外國人投資台灣，可能涉及外國人投資申請及資金匯入程序。
- 外國投資人希望來台工作，還需要另外評估工作許可及居留相關規定。
- 經營特許行業，可能需要取得目的事業主管機關核准或許可。

跨境交易可能涉及零稅率適用、境外所得及相關交易憑證判斷。

這些案件往往不能只用一般公司設立的流程處理，建議創業者在正式投入資金或開始營業前，先確認相關規定及申請條件。

## 八、哪些事情不能完全交給記帳士事務所？

雖然記帳士事務所可以協助處理許多行政及稅務工作，但並不代表創業者可以將所有事情完全交由事務所負責。

以下幾件事情，仍然需要創業者自行參與：

### 1. 提供真實且完整的交易資料

事務所必須依照客戶提供的資料處理帳務。如果有收入未提供、支出憑證遺失，或實際交易與提供的資料不一致，就可能影響帳務及申報正確性。

### 2. 決定公司的經營方向

公司要賣什麼產品、提供什麼服務、與誰合作、是否增加投資人，這些都是經營者應自行決定的商業事項。事務所可以從稅務及登記角度提供建議，但不能代替經營者做所有商業決策。

### 3. 配合銀行開戶及資金往來

公司籌備處或正式公司帳戶的開立，通常需要負責人及相關人員配合銀行的身分確認、審查及文件要求。事務所可以協助準備資料及提醒流程，但不能保證銀行一定核准開戶。

想更了解公司籌備處帳戶開設者，可以參考這一篇：[開設銀行籌備處帳戶需要注意什麼？](./company-reg-15.html)

### 4. 取得主管機關核准或許可

涉及特許行業、外國人投資、工作許可或其他主管機關審查的案件，即使委託事務所協助申請，最終仍由主管機關依照規定審核，不能保證一定取得核准。

### 5. 處理法律訴訟及其他專業事項

如果公司涉及股東爭議、契約糾紛、勞資爭議或訴訟案件，應視情況委託律師或其他適當專業人士處理。

因此，事務所與創業者之間比較理想的合作方式，是由事務所協助處理專業的帳務、稅務及登記行政工作，而創業者則負責提供資料、確認交易內容及做出經營決策。

## 九、創業者應該如何選擇記帳士事務所？

市面上有許多提供記帳及報稅服務的事務所，但不同事務所的服務內容、收費方式及專業經驗可能有所差異。

創業者在選擇時，不建議只比較每個月的記帳費用，也應該了解以下幾個重點：

- 服務範圍是否清楚： 是否包含營業稅、營所稅、扣繳及各類所得申報？公司變更、薪資及其他行政服務是否另外收費？
- 是否具備相關專業資格： 了解實際承辦人員的專業背景，以及涉及會計師簽證等事項時，是否由符合資格的人員辦理。
- 是否能提供適當的諮詢： 當公司遇到新的交易模式、投資或稅務問題時，是否有適當的溝通及諮詢管道？
- 特殊案件是否有處理經驗： 如果涉及外國人投資、特許行業或跨境交易，應確認事務所是否能協助評估相關程序。
- 資料及帳務交接是否便利： 是否有固定窗口、資料傳送方式及帳務交接機制，避免日後更換事務所時產生困難。

對創業初期的企業而言，選擇一間能夠理解自身營業模式、願意溝通並且能持續提供帳務及稅務協助的事務所，往往比單純追求最低價格更重要。

## 十、事務所的建議：不要等到遇到問題，才開始找人協助

很多創業者會認為，剛開始營業規模很小，等到收入增加、開始請員工，或真的遇到稅務問題時，再找記帳士事務所就好。

但實務上，有些問題如果能在創業前先確認，往往可以減少後續調整的成本。

例如，公司設立時就先確認營業項目及登記地址，可以降低日後變更的機會；開始營業時就建立公司與個人帳戶分開的習慣，可以減少後續帳務整理的困難；開始聘僱員工前先確認相關投保及薪資申報義務，也能降低違規風險。

因此，**我們建議創業者不一定要等到公司規模很大，才開始尋求專業協助。即使只是剛開始接案、經營網路商店或準備成立一間小型公司，也可以先透過諮詢了解適合自己的設立方式及後續應注意的事項**。

> 記帳士事務所的角色，不只是協助企業完成報稅，而是讓創業者在面對公司設立、帳務處理及稅務申報時，有專業人員可以討論及協助。
> 
> 如果你正準備創業，或已經開始營業，卻不確定自己的公司是否需要辦理哪些登記、申報及帳務工作，不妨先整理目前的營業模式與需求，與專業事務所討論。把該做的事情及早安排好，才能把更多時間留給真正重要的業務經營。
