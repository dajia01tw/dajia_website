## 蝦皮、露天、網路商店賺錢要報稅嗎？網路賣家的稅務入門

現在想創業，不一定要先租店面，也不一定要準備大量資金。只要有商品、有貨源，透過蝦皮、露天、市集或自己架設的網路商店，就有機會開始做生意。

不少人一開始只是利用下班時間賣東西，可能是販售自己進貨的商品、手作商品、服飾、生活用品，或經營網路選物店。剛開始每個月營業額不高，便容易產生疑問：「我只是網路賣家，也沒有實體店面，需要辦理公司或行號登記嗎？平台已經幫我收錢了，還需要自己報稅嗎？」

事實上，網路銷售並不代表可以免除稅務義務。是否需要辦理登記及申報，主要還是要看銷售行為的性質、營業規模，以及是否具有持續營業的情形。

這篇文章就從網路賣家最常遇到的問題出發，帶你了解網路銷售的基本稅務觀念。

## 一、只是偶爾在網路上賣東西，也需要辦理登記嗎？

首先要區分的是：你是在出售自己的個人物品，還是已經開始經營一門生意？

例如，偶爾將家中不再使用的二手衣物、家具、3C產品放上網路平台出售，通常與以營利為目的、持續進貨銷售的商業活動不同。

但如果你開始固定向供應商進貨，再透過蝦皮、露天或其他網路商店銷售，並且持續經營、賺取價差，即使沒有店面，也可能已經具有營業性質。

以下幾種情況，可以幫助你初步判斷：

| 網路銷售情況 | 初步判斷 |
|------|------|
| 偶爾出售家中不需要的二手物品 | 通常不屬於持續經營的網路商業活動 |
| 固定進貨，再透過平台銷售商品 | 可能具有營業性質，應評估登記及報稅義務 |
| 自己製作商品，持續接單販售 | 可能屬於持續營業活動 |
| 經營網路商店，有固定商品、價格及銷售管道 | 應評估是否需要辦理營業及稅籍登記 |
| 同時在多個平台或社群銷售商品 | 應合併考量整體營業情形，而非只看單一平台 |

因此，不能單純以「有沒有實體店面」或「是不是在蝦皮賣東西」來判斷是否需要登記。真正重要的是，你是否已經開始以營利為目的，持續從事商品或勞務銷售。

## 二、網路賣家營業額多少，需要辦理稅籍登記？

這是網路賣家最關心的問題之一。

依目前規定，自2025年1月1日起，銷售貨物的營業人，每月銷售額未達新臺幣10萬元；銷售勞務的營業人，每月銷售額未達新臺幣5萬元，得免辦稅籍登記。

換句話說，如果你是在網路上銷售一般商品，例如服飾、食品、生活用品或3C商品，原則上應注意每月銷售額是否達到10萬元的門檻。

| 銷售類型 | 每月銷售額未達以下金額，得免辦稅籍登記 |
|------|------|
| 銷售貨物 | 10萬元 |
| 銷售勞務 | 5萬元 |

不過，這裡有幾個重要觀念需要特別注意。

### 1. 判斷的是每月銷售額，不是實際賺到的利潤

假設你在蝦皮銷售服飾，某個月總銷售金額為12萬元，進貨成本、平台手續費及物流費合計10萬元，最後實際賺到2萬元。

**判斷是否達到稅籍登記門檻時，並不是看最後賺到的2萬元，而是要看銷售額**。因此，不能因為利潤很低，就認為不需要辦理登記。

### 2. 不同平台的銷售額，不能分開計算來規避門檻

假設你同時經營蝦皮、露天及自己的網路商店：

- 蝦皮每月銷售額：5萬元
- 露天每月銷售額：3萬元
- 自有網路商店每月銷售額：4萬元

合計每月銷售額為12萬元。不能因為每個平台的銷售額都未達10萬元，就認為不需要辦理稅籍登記。

**判斷時應依實際營業情形，整體檢視銷售額，而不是只看單一平台**。

### 3. 未達稅籍登記門檻，不代表所有稅務義務都免除

每月銷售額未達上述門檻，得免辦稅籍登記，但不代表相關所得一律免稅，也不代表任何情況都不需要辦理其他登記。

如果已經有持續經營的情形，仍應依實際業務型態，確認是否涉及商業登記、特許行業或其他法令要求。

## 三、網路賣家需要繳哪些稅？營業稅與所得稅有什麼不同？

開始經營網路商店後，最常接觸到的稅務主要是營業稅及所得稅。

這兩種稅的課稅基礎不同，不能混為一談。

### 1. 營業稅：主要看銷售額

營業稅是針對商品或勞務銷售所涉及的稅負。

如果網路賣家已經辦理稅籍登記，後續要依稅籍核定的課稅方式處理。一般使用統一發票的營業人，通常適用5%的營業稅稅率，並依規定申報營業稅。

至於規模較小的營業人，是否核定為小規模營業人、是否使用統一發票，以及適用何種課稅方式，仍須由稅捐機關依營業性質及實際情況認定。

因此，**不是所有網路賣家一開始都必須使用統一發票**，也不是只要在網路上銷售商品，就一定適用完全相同的課稅方式。

### 2. 所得稅：主要看所得及經營組織

網路銷售所產生的所得，還需要依照經營者的身分及組織型態，判斷如何申報所得稅。

例如：

- **個人經營：**如果屬於持續營業活動，應依實際經營情況判斷所得性質及申報方式。
- **獨資或合夥商號：**商號本身不是獨立的營利事業所得稅納稅主體，其營利所得依規定歸課獨資資本主或合夥人。
- **有限公司：**公司原則上應就年度所得申報營利事業所得稅；公司盈餘分配給股東時，股東還要依規定處理個人綜合所得稅。

所以，網路賣家究竟應該用個人名義經營、成立行號，還是成立有限公司，除了考量營業規模，也應將所得稅及未來經營需求一起納入評估。

## 四、平台已經代收款項，還需要自己申報嗎？

不少網路賣家會透過蝦皮、露天或其他電商平台收款。消費者付款後，平台可能先代為收取貨款，再扣除平台服務費、金流費用或其他相關費用，最後將款項撥入賣家的銀行帳戶。

這種交易方式容易讓賣家誤以為：「平台已經幫我處理收款，是不是就不用再處理稅務？」

答案並不是如此。

平台代收款項，主要是協助處理交易金流，並不代表平台已經代替賣家完成營業稅或所得稅申報。

舉例來說：

假設某網路賣家當月商品銷售金額為10萬元，平台扣除服務費及其他費用共5,000元，最後匯入銀行帳戶95,000元。

| 項目 | 金額 |
|------|------|
| 商品銷售金額 | 100,000元 |
| 平台服務費及相關費用 | 5,000元 |
| 實際匯入銀行帳戶 | 95,000元 |

在帳務處理上，不能直接將匯入銀行的95,000元當成全部銷售收入。商品銷售收入與平台收取的費用，應分別記錄及處理。

此外，**網路交易資料及金流紀錄可能成為稅捐機關掌握營業情形的參考資料**。賣家應保留平台訂單、銷售明細、退款紀錄、平台費用及銀行入帳資料，以利日後核對及申報。

## 五、網路賣家應該保留哪些帳務資料？

網路銷售的交易筆數可能很多，而且常常涉及不同平台、不同付款方式及退貨退款。如果平時沒有整理資料，到了申報期間才開始整理，容易發生收入漏列、成本費用無法核對等問題。

建議網路賣家從開始經營時，就建立基本的帳務管理習慣。

以下是幾種建議保留的資料：

| 資料類型 | 建議保留內容 |
|------|------|
| 銷售收入 | 平台訂單、商品銷售明細、交易紀錄 |
| 退款及折讓 | 退貨紀錄、退款明細、折讓資料 |
| 進貨成本 | 進貨發票、收據、供應商交易紀錄 |
| 平台費用 | 平台服務費、金流手續費、廣告費明細 |
| 物流費用 | 宅配、超商取貨及其他運費資料 |
| 銀行金流 | 銀行存摺、轉帳紀錄、平台撥款明細 |

尤其是進貨成本及相關費用，應盡可能取得合法憑證。若只有銀行轉帳紀錄，卻沒有足以證明交易內容的資料，未來在帳務及稅務處理上可能產生困難。

另外，建議盡可能將營業收支與個人生活支出分開管理，避免私人消費、家庭支出與網路商店的收付款混在一起。

## 六、網路賣家應該成立行號，還是有限公司？

當網路商店逐漸有穩定訂單，甚至開始聘請員工、租用倉庫或擴大進貨規模時，就可以進一步思考是否要成立正式的營業組織。

一般而言，網路賣家常見的選擇包括個人經營、獨資行號及有限公司。

| 比較項目 | 個人經營 | 獨資行號 | 有限公司 |
|-----|-----|-----|-----|
| 組織型態 | 個人名義 | 商業組織 | 法人 |
| 設立程序 | 依實際情況判斷 | 辦理商業及相關登記 | 辦理公司設立登記 |
| 責任 | 個人承擔相關責任 | 獨資資本主負無限責任 | 股東原則上以出資額為限負責 |
| 所得稅 | 依所得性質及規定申報 | 營利所得歸課資本主 | 公司申報營利事業所得稅 |
| 適合情況 | 初期、小規模或尚未形成持續營業 | 個人經營、規模較小的生意 | 希望建立公司制度、擴大營運或引進股東 |

如果只是剛開始測試市場，可以先評估實際營業情況及登記義務，不必急著成立規模較大的公司。

但如果已經有固定客戶、穩定營收、持續進貨，甚至準備聘請員工或與其他企業合作，就應該及早規劃適合的營業組織。

特別提醒，成立行號或公司不只是取得一張登記證明，後續還會涉及稅籍登記、帳務處理、營業稅及所得稅申報等事項。創業初期先規劃清楚，通常比營運一段時間後才補辦登記、整理帳務來得省事。

## 七、事務所建議：網路賣家不要等到營業額變大，才開始注意稅務

網路創業的門檻相對較低，但不代表稅務問題可以等到生意做大之後再處理。

我們在協助創業者時，常發現有些網路賣家已經經營一段時間，甚至每個月都有穩定收入，卻沒有完整保留銷售及進貨資料，也不清楚自己是否已經達到稅籍登記門檻。

等到需要辦理登記、申報稅務，或是遇到稅捐機關詢問時，才發現過去的交易紀錄不容易整理。

因此，對於準備經營網路商店的人，我們建議先做好以下幾件事：

- **確認銷售性質**：是偶爾出售個人物品，還是已經開始持續進貨及銷售？
- **統計整體營業額**：不要只看單一平台，應將不同平台及其他銷售管道一併納入評估。
- **確認登記義務**：依每月銷售額、營業型態及相關規定，確認是否需要辦理稅籍及其他登記。
- **建立帳務紀錄**：保存訂單、進貨憑證、平台費用及銀行收款資料。
- **選擇合適組織**：依照經營規模、責任風險及未來發展，評估個人經營、行號或有限公司。

如果你已經開始經營蝦皮、露天或自己的網路商店，卻不確定是否需要辦理登記，或不知道營業額應該如何計算，可以先讓專業人員協助檢視目前的經營模式。

本事務所可協助創業者辦理公司設立、行號登記、稅籍登記，以及後續帳務處理與稅務申報。從創業初期的登記規劃，到營運後的日常帳務管理，都可以依照實際需求提供協助。

**網路創業不只是把商品上架、收到訂單，更重要的是讓生意在合法、清楚的帳務架構下穩定成長**。

> 本文係以一般網路商品銷售情形為例，實際登記及課稅方式仍須依營業型態、銷售內容、營業規模及主管機關認定辦理。特許行業、跨境交易及其他特殊交易模式，應另行評估。
