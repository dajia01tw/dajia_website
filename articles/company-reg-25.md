## 找記帳士事務所辦理公司設立，與自己申請有什麼差別？創業者必看的設立流程比較

準備創業時，除了決定要成立有限公司還是股份有限公司，接下來就會遇到一個實際問題：公司設立要自己向政府機關申請，還是委託記帳士事務所代辦？

有些創業者認為，現在政府有提供線上申辦系統，公司設立資料也可以自己填寫，如果只是成立一家小公司，應該不需要另外花錢請事務所代辦。

也有人擔心，自己不熟悉公司法及相關申請程序，萬一名稱、營業項目、資本額或申請文件填錯，反而要花更多時間補件及修改。

事實上，自己申請與委託事務所辦理公司設立，各有適合的情況。兩者最大的差別，不只是有沒有支付代辦費，而是申請過程中由誰協助判斷設立條件、準備文件、處理資本額驗證，以及後續稅籍登記等事項。

本文就從創業者的角度，整理兩種方式的差異，協助你判斷哪一種比較適合自己。

## 一、自己申請公司設立，可以嗎？

**答案是可以**。

在台灣成立有限公司或股份有限公司，並沒有規定一定要委託記帳士事務所代辦。創業者可以自行準備相關資料，透過經濟部公司與商業及有限合夥一站式線上申請系統，或依規定向主管機關提出申請。

不過，公司設立並不是單純填寫一份申請表就完成，通常還需要處理以下事項：

- 決定公司名稱及營業項目。
- 確認公司登記地址及使用條件。
- 決定公司組織型態、股東及負責人。
- 決定資本額及股東出資方式。
- 開立公司籌備處銀行帳戶。
- 股東繳納股款及辦理資本額查核簽證。
- 向主管機關申請公司設立登記。
- 辦理稅籍登記及後續發票相關事項。

其中，有些資料可以由創業者自行準備，但也有部分程序涉及專業判斷或法定專業簽證。

例如，依公司法第7條規定，公司設立登記的資本額，應經會計師查核簽證。因此，即使創業者選擇自行辦理公司設立，也仍然需要委託符合資格的會計師辦理資本額查核簽證。

換句話說，**自己申請公司設立，不代表所有程序都可以完全不需要專業人員協助**。

## 二、自己申請與委託事務所辦理，主要差別在哪裡？

兩種方式最明顯的差異，就是申請過程中由誰負責準備資料、確認規定及處理申請程序。

以下整理比較：

| 比較項目 | 自己申請公司設立 | 委託記帳士事務所辦理 |
|-----|-----|-----|
| 公司名稱及營業項目 | 自行查詢及決定 | 可由專業人員協助評估 |
| 公司組織及股權安排 | 自行研究及規劃 | 可依創業需求討論 |
| 登記地址確認 | 自行確認使用條件 | 可協助提醒應注意事項 |
| 申請文件準備 | 自行製作及檢查 | 由事務所協助準備及確認 |
| 資本額查核簽證 | 仍須委託會計師 | 可協助安排會計師簽證 |
| 政府申請程序 | 自行送件及追蹤 | 由事務所依委託範圍辦理 |
| 補件及修改 | 自行了解原因及處理 | 可由承辦人員協助處理 |
| 稅籍登記 | 自行辦理或依整合流程申請 | 可依委託內容協助辦理 |
| 設立後帳務及稅務 | 自行尋找相關資訊 | 可進一步委託記帳及報稅 |
| 費用 | 可節省部分代辦服務費 | 需支付代辦服務費 |

需要注意的是，委託事務所並不代表所有工作都由事務所無條件包辦。實際服務範圍仍應以雙方約定為準，例如公司設立是否包含稅籍登記、發票申請及後續記帳服務，都應該事先確認。

## 三、自己申請公司設立，最容易遇到哪些問題？

如果創業者本身熟悉公司登記程序，或有相關經驗，自己申請確實可以節省部分代辦費用。

但對第一次創業的人來說，真正花時間的地方，往往不是填寫申請表，而是如何判斷資料應該怎麼準備，以及遇到問題時如何處理。

### 1. 公司名稱及營業項目不知道怎麼選

公司設立前，需要先決定公司名稱，並選擇適當的營業項目。

公司名稱除了要符合相關規定，也需要先辦理名稱及所營事業預查，確認是否可以使用。

至於營業項目，創業者常常會遇到以下問題：

- 公司目前只提供顧問服務，未來可能增加商品銷售，是否需要一起登記？
- 公司經營網路商店，應該選擇哪些營業項目？
- 公司除了主要業務之外，也會收取佣金或介紹費，是否需要增加其他項目？
- 某些營業項目是否涉及特許或許可規定？

如果只依照目前正在做的工作選擇營業項目，卻沒有考慮未來的營運模式，可能在實際營業後才發現需要辦理變更登記。

不過，營業項目也不是登記越多越好。應該依照實際經營內容及未來合理規劃選擇，不宜為了方便而任意填列。

### 2. 公司登記地址不一定可以直接使用

很多創業者會想：「我在家裡辦公，直接用住家地址登記公司可以嗎？」

這個問題不能只看房屋所有權，也不能只看房東是否同意。

**以台北公司登記為例**，公司登記地址可能涉及建築物使用、土地使用分區、房屋用途、所在地相關管理規定，以及租賃契約或其他使用權源等問題。因此，設立登記前應先進行營業場所審查，待都發局、建管處等查核單位認定均符合規定核發審查意見表後方能合法使用、並進行公司登記。

例如：

- 自有住宅是否可以作為公司登記地址？
- 租來的辦公室是否可以登記公司？
- 商務中心提供的地址是否符合登記及實際營業需求？
- 公司登記在住家，是否會影響房屋稅或其他相關稅務？

不同地點及實際使用情況可能有不同結果，因此建議在租屋或簽訂商務中心合約之前，先確認地址是否適合公司登記。

如果自行申請，創業者就需要自己了解相關規定並確認資料；委託事務所時，則可以先請承辦人員協助檢視地址可能涉及的問題。

### 3. 資本額不知道應該設定多少

公司設立時，創業者需要決定資本額。

有些人認為資本額越低越好，因為不需要準備太多資金；也有人認為公司資本額應該設定得高一點，才比較有規模。

但資本額並不是單純填寫一個數字，而是應該考慮公司初期的營運需求。

例如：

- 公司是否需要租辦公室？
- 是否需要購買設備或進貨？
- 是否需要聘請員工？
- 客戶或合作廠商是否對資本額有要求？
- 公司未來是否有投資人加入或增資規劃？

此外，公司資本額涉及股東實際出資、銀行資金存入及會計師查核簽證，不能只是為了符合某個數字而任意填寫。

如果沒有事先規劃，可能出現資本額不足以支應初期營運，或股東實際出資與登記資料不一致等問題。

### 4. 不清楚申請流程及文件之間的關係

公司設立會涉及不同階段的文件及程序。

例如，公司名稱及營業項目預查、銀行籌備處帳戶、股款繳納、資本額查核簽證，以及公司設立登記等。

這些程序有一定的先後關係。如果創業者不熟悉流程，可能在文件尚未準備完整時就先進行下一步，導致需要重新準備或補充資料。

另外，若公司有多位股東，還需要注意股東資料、出資比例、章程及相關決議文件是否一致。

這些都是第一次申請公司設立時，比較容易花費時間的地方。

## 四、委託記帳士事務所辦理公司設立，有哪些好處？

委託事務所代辦的價值，不只是幫忙送件，更重要的是在公司成立之前，先協助創業者釐清設立條件及相關問題。

### 1. 先了解營業模式，再規劃公司設立資料

不同創業模式，適合的公司設立方式可能不同。

例如：

- 個人接案工作者，未來希望聘請員工及擴大經營。
- 網路賣家，除了網路銷售，也可能有實體門市。
- 兩位朋友共同創業，需要討論股東出資及持股比例。
- 預計引進外部投資人，希望未來可以辦理增資。
- 外國人準備來台投資，需要先確認投資資格及相關程序。

這些情況都不應該只從「如何把公司登記完成」的角度思考。

**事務所可以先了解創業者的營業模式、股東結構及未來規劃，再協助評估公司型態、營業項目及其他設立資料**。

### 2. 協助確認公司名稱及營業項目

創業者通常比較清楚自己要做什麼生意，但不一定熟悉政府登記使用的營業項目分類。

例如，實際業務可能同時包含商品銷售、顧問服務、網路平台經營及佣金收入。

事務所可以依照實際營業內容，協助確認適合的營業項目及是否涉及特別許可。

不過，如果經營內容涉及特許行業，仍然需要依照主管機關規定另外取得許可，不能只因為公司登記有列入相關營業項目，就認為可以直接開始營業。

### 3. 協助準備文件及處理申請程序

公司設立需要準備的資料，會依照公司類型、股東人數及實際情況有所不同。

委託事務所後，通常可以由承辦人員協助整理申請資料、確認文件內容、安排資本額查核簽證及辦理相關申請程序。

如果主管機關要求補充資料或修改文件，也可以由承辦人員協助了解原因並處理。

對於平常還有工作、沒有時間研究申請流程的創業者來說，這樣可以減少自行摸索的時間。

### 4. 可以一併規劃設立後的稅務及帳務事項

公司設立完成，並不代表創業者的行政工作就全部結束。

接下來還可能涉及：

- 稅籍登記及營業稅課稅方式。
- 統一發票使用及相關申請。
- 公司帳戶及日常金流管理。
- 公司憑證保存及帳務整理。
- 營業稅及營利事業所得稅申報。
- 聘僱員工後的薪資及扣繳申報。

如果從公司設立階段就先了解這些事項，通常比較容易建立完整的經營及帳務管理制度。

尤其**對第一次創業的人來說，設立公司只是第一步，後續如何正確處理帳務及稅務，才是長期經營時需要持續注意的事情**。

## 五、委託事務所代辦公司設立，需要支付哪些費用？

創業者在比較自己申請與委託事務所時，最常關心的問題之一就是費用。

一般來說，公司設立相關費用可以分成幾個部分：

| 費用項目 | 說明 |
|-----|-----|
| 政府規費 | 依公司名稱預查、設立登記及相關申請項目收取 |
| 會計師資本額查核簽證費 | 公司設立資本額依法需要會計師查核簽證 |
| 事務所代辦服務費 | 委託事務所協助準備文件及辦理申請的服務費 |
| 其他必要支出 | 例如銀行開戶相關費用、印章、地址租用或其他實際支出 |

需要特別注意，**自己申請公司設立，通常可以省下的是代辦服務費，而不是所有設立費用**。

例如，公司資本額查核簽證仍然需要依法辦理，不會因為創業者自行送件就可以省略。

另外，不同事務所的報價內容可能不同，有些只包含公司設立登記，有些則可能包含名稱預查、資本額查核簽證、稅籍登記及其他後續服務。

因此，詢價時不宜只比較總價，應該先確認報價包含哪些項目，以及哪些費用需要另外支付。

## 六、哪些情況適合自己申請？哪些情況建議委託事務所？

自己申請或委託代辦，沒有絕對哪一種比較好。以下整理幾種常見的創業情境：

| 創業情況 | 建議方式 | 原因 |
|-----|-----|-----|
| 一人創業，營業內容單純，且熟悉公司設立流程 | 可考慮自行申請 | 可以節省部分代辦費用 |
| 第一次創業，對公司登記及稅務完全不熟悉 | 建議委託事務所 | 可減少自行研究及資料準備的時間 |
| 有兩位以上股東，需要討論出資及持股比例 | 建議先找專業人員討論 | 股東權利及出資安排應在設立前釐清 |
| 未來預計引進投資人或辦理增資 | 建議委託或先行諮詢 | 應事先考慮公司型態及股權規劃 |
| 有特殊營業項目或特許行業需求 | 建議先尋求專業協助 | 可能涉及額外許可及主管機關規定 |
| 外國人投資成立台灣公司 | 建議委託熟悉外資案件的專業人員 | 可能涉及投資審查及資金匯入等程序 |
| 已經有會計或公司登記相關經驗 | 可自行評估辦理 | 但仍須確認最新申請規定及必要簽證 |

特別提醒，若公司涉及外國人投資、特殊行業許可、多位股東或未來引進投資人等情況，建議不要只以代辦費用作為選擇依據。

這些案件在公司成立之前，可能就需要先確認投資資格、公司架構及營業內容。若設立後才發現原本安排不適合，可能還需要辦理變更登記，甚至重新規劃。

## 七、委託記帳士事務所辦理公司設立，應該注意哪些事情？

如果決定委託事務所，建議在正式委託前，先了解以下幾個重點。

### 1. 是否真正了解你的營業模式？

好的設立服務，不應該只是拿到資料後直接填寫申請表。

例如，你準備經營的是網路商店、顧問服務、餐飲業，還是涉及外國投資的業務，不同營業模式可能會有不同的登記及稅務注意事項。

建議選擇願意先了解實際營業內容，再協助規劃設立資料的事務所。

### 2. 報價包含哪些服務？

詢價時可以確認：

- 是否包含公司名稱預查？
- 是否包含營業項目規劃？
- 是否包含公司設立登記？
- 是否包含會計師資本額查核簽證？
- 是否包含稅籍登記？
- 是否包含統一發票相關申請？
- 是否包含公司設立後的記帳及報稅服務？

不同事務所的服務內容可能不同，建議事先確認，避免因為報價範圍不同而產生誤解。

### 3. 設立完成後，是否能繼續提供帳務及稅務服務？

公司成立之後，還有許多後續工作需要處理。

例如營業稅申報、營所稅申報、薪資扣繳、股東往來及各項帳務整理等。

如果設立公司與後續記帳服務可以由同一個事務所協助，通常比較容易延續設立時已經確認的資料，也能減少重新交接的時間。

### 4. 是否具備處理特殊案件的經驗？

如果公司有外國人投資、特許行業、跨境交易或多位股東等特殊需求，建議事先確認事務所是否熟悉相關案件。

一般公司設立與特殊案件的處理方式可能不同，不應該只以一般設立案件的報價及流程來評估。

## 八、事務所建議：公司設立可以自己辦，但設立前的規劃更重要

對於第一次創業的人來說，自己申請公司設立並不是不可能。

如果公司股東只有一人、營業內容單純、登記地址沒有特殊問題，而且創業者願意花時間研究申請程序，自行辦理確實可以節省部分代辦費用。

但如果公司涉及多位股東、特殊營業項目、外國人投資，或未來有引進投資人及擴大經營的規劃，建議在設立前先尋求專業協助。

因為公司設立不只是取得一張核准文件，還包括公司型態、股東出資、資本額、營業項目及稅務安排等一系列決策。

如果一開始沒有規劃清楚，日後可能需要辦理變更登記、調整股權或重新整理帳務，反而增加時間及成本。

我們建議創業者可以先評估自己的時間、專業能力及公司設立的複雜程度，再決定是否委託事務所。

> 自己申請，省下的是部分代辦費用；委託專業人員，買到的則是流程協助、文件檢查及設立前的專業討論。
> 
> 真正重要的不是哪一種方式比較便宜，而是公司能否從成立第一天起，就建立適合自己的組織架構及帳務制度。
